# Fun Next.js with Alessio

授業の前日に「明日は授業あるよ」と Discord に通知してくれる GitHub Actions のリマインダーです。
学校の授業用に作った、少しだけ遊び心のある自動化です。

---

## できること

毎日 21:00（JST）に自動で実行されます。
翌日が授業日だった場合のみ、Discord に通知が送られます。
通知には授業名、日付と時間、関連する Issue、ランダムな一言が含まれます。

---

## 授業名

今日アレッシオの楽しいNext.js

---

## 授業日の管理

授業日と時間は JSON ファイルで管理しています。
日付を追加・変更するだけで対応できます。
年をまたぐ場合もそのまま書けます。

---

## ランダム文言について

通知に含める一言は、あらかじめ用意した文章の中から毎回ランダムで1つ選ばれます。
ふざけすぎない程度に、自由に追加・変更して問題ありません。

---
## アイコンについて

いまは適当なアイコンにしています。もしよかったらいい感じのやつに変えてください。
まあそのへんは任せます

---
## 関連 Issue について

リポジトリ内の open な Issue を取得して、通知に一覧で表示します。
授業でやること、課題メモ、気になる点や質問などを Issue として管理する想定です。
授業前の整理用として使うと便利です。

---



## 実行タイミング

毎日 21:00（JST）に自動実行されます。
また、Actions 画面から手動で実行することもできます。
